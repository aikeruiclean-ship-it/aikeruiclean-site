## 三、注册步骤

### ThomasNet（约 15 分钟）

```
1. 打开 https://business.thomasnet.com/register
2. 填写公司名 + 邮箱 + 密码
3. 选择 "Manufacturer" 作为 Company Type
4. 粘贴上面的公司简介到 Description 栏
5. 勾选产品类别（6个类别）
6. 上传 3-5 张产品/工厂照片
7. 提交 → 等待审核（1-3 个工作日）
```

### Made-in-China（约 30 分钟）

```
1. 打开 https://passport.made-in-china.com/signup
2. 用企业邮箱 info@aikeruiclean.com 注册
3. 选择 "Free Membership" （免费版即可）
4. 填写公司信息（粘贴上面的模板）
5. 上传营业执照扫描件（审核需要）
6. 添加至少 10 个产品（用上面模板，每个配1张照片）
7. 提交 → 等待审核（1-2 个工作日）
8. 审核通过后完善工厂相册 + 认证证书
```
