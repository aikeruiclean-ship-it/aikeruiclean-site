## 二、分配规则

### 2.1 分配方式：轮询（Round-Robin）

所有新线索按照 **固定顺序循环分配**，确保每位业务员获得等量的线索。

### 2.2 分配顺序

| 序号 | 业务员 | 电话 | 邮箱 |
|------|--------|------|------|
| 1 | Jennifer | 18133073186 | jennifer@czhclean.com |
| 2 | Wisdom | 17352977258 | wisdom@czhclean.com |
| 3 | Keke | 19159116875 | keke@czhclean.com |
| 4 | Liv | 18324956076 | liv@czhclean.com |

分配循环：**Jennifer → Wisdom → Keke → Liv → Jennifer → ...**

### 2.3 分配时机

- **网站表单提交时**：Google Apps Script 实时检测新邮件 → 即时分配转发
- **WhatsApp 留言**：系统自动转发到 info@ → 脚本检测 → 即时分配
- **直接邮件**：脚本定时检测（每 5 分钟轮询）→ 分配

### 2.4 响应时效

- **24 小时内**业务员必须首次回复客户
- 超时未回复 → 该线索自动转给下一位业务员

## 三、业务员操作流程

### 3.1 收到新线索通知

你收到一封被自动转发的客户询单邮件，内容包含：

```
┌─────────────────────────────────────┐
│  新线索 #[编号] — [客户公司]         │
│  ─────────────────────────────       │
│  客户姓名:    [name]                 │
│  公司:        [company]              │
│  国家:        [country]              │
│  电话:        [phone]                │
│  邮箱:        [email]                │
│  产品:        [product]              │
│  数量:        [quantity]             │
│  留言:        [message]              │
│                                      │
│  来源: 网站询单 / WhatsApp / 直接邮件  │
│  时间: [timestamp]                   │
└─────────────────────────────────────┘
```

### 3.2 跟进步骤

```
Step 1 - 确认收到（30分钟内）
  → 回复客户邮件 / WhatsApp，确认已收到需求

Step 2 - 需求确认（4小时内）
  → 确认产品型号、数量、技术参数
  → 确认是否需要视频看厂

Step 3 - 报价（24小时内）
  → 根据三级价格体系提供报价
    · L1 标准品 → 直接报价
    · L2 中高价 → 确认参数后报价
    · L3 OEM → 评估后出方案报价

Step 4 - 更新线索跟踪表
  → 在 Google Sheet 中记录跟进状态
```

### 3.3 跟进状态定义

| 状态 | 说明 |
|------|------|
| 🟢 新线索 | 刚分配，尚未联系 |
| 🔵 跟进中 | 已联系客户，正在沟通 |
| 🟡 报价中 | 已提供报价，等待客户决策 |
| 🟠 谈判中 | 客户有意向，在谈价格/条款 |
| 🟣 已成交 | 客户已下单 |
| 🔴 已关闭 | 客户无意向或未回复超 2 周 |

## 四、三级价格体系快速指引

| 级别 | 包含产品 | 定价方式 |
|------|----------|----------|
| **L1 标准耗材** | 盘刷 / 吸水胶条 / 过滤器 / 碳刷 / 法兰 / 边刷 / 滚刷 / 百洁垫 | 公开标价 $4–$15 |
| **L2 中高价** | 针盘 / 电机 / 电池 / 电磁阀 / 轮子 / 定制刷 | 询价：确认参数 + MOQ + FOB + 交期 |
| **L3 OEM/定制** | 非标配件 / 特殊结构件 / OEM 方案 | 评估流程：需求→图纸→报价→生产（需主管审批） |

## 六、异常处理

| 异常情况 | 处理方式 |
|----------|----------|
| 业务员休假 | 手动跳过，线索给下一位 |
| 客户重复询价 | 分配给原跟进业务员 |
| 客户指定业务员 | 直接转给指定人 |
| 24h 未回复 | 自动转给下一位业务员 |
| 大客户/OEM 需求 | 分配给主管或团队负责人 |
